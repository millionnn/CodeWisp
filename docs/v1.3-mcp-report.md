# V1.3 MCP Tool Integration Report

**日期：** 2026-09-01  
**状态：** 已完成  
**版本：** 1.3.0

---

## 概述

V1.3 将 MCP 作为 **Tool Extension Layer** 接入 CodeWisp：外部能力经 Adapter 进入现有 ToolRegistry，与 Built-in / Git / LSP 共用 Permission、AgentEvent、Context 与 Trace，而不是第二套 Agent Runtime。

## 配置

`workspace/.codewisp/mcp.json`（优先）或 `~/.codewisp/config.json`：

```json
{
  "mcpServers": {
    "demo": {
      "command": "python3",
      "args": ["-m", "backend.app.mcp.demo_server"],
      "enabled": true
    }
  }
}
```

环境变量展开：`${TOKEN}`；**禁止**把 API key 写入 SQLite。

## Permission

| 分类 | 策略 |
|------|------|
| read / search / get / list | ALLOW |
| write / create / update / delete | ASK |
| shell / exec / destructive | DENY |

MCP annotations：`readOnlyHint` / `destructiveHint` 优先。

## Security

- Server allowlist = 配置中的 keys
- Tool 调用走 PermissionHandler
- Workspace：stdio cwd / `CODEWISP_WORKSPACE`
- Secret：仅 env；不入 Session / Memory / SQLite payload

---

## Explicit non-goals（本版本不做）

- 全 MCP 生态 / 全 transport / OAuth
- Resource / Prompt 全功能
- Multi-Agent / Web UI
- 重写 AgentLoop 或第二套 ToolExecutor
- 新增 `mcp_*` 数据库表
